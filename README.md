Começou com uma curiosidade: por que gerar um QR Code de PIX é mais chato do que
deveria ser?

A resposta é que desenhar o código já é problema resolvido há anos. A parte
difícil é montar o texto que vai dentro dele. O BR Code do PIX usa estrutura EMV
com CRC16, senha de WiFi com ponto e vírgula corta o payload no meio, e número
de WhatsApp com parêntese gera link quebrado.

Virou uma biblioteca sem dependência nenhuma, mais um site que roda inteiro no
navegador, sem mandar chave PIX ou senha de rede para servidor nenhum.

`TypeScript` `Next.js` `51 testes`

## O que eu gosto de construir

<table>
<tr>
<td width="50%" valign="top">

### 🔁 Coisas que rodam sozinhas

Fluxos que coletam dados, filtram por regra e entregam o resultado sem eu
precisar olhar. Geralmente com **n8n**, Node e Python amarrados por um banco.

A graça está em fazer cada etapa aguentar rodar duas vezes sem estragar nada.

</td>
<td width="50%" valign="top">

### 🔌 Sistemas que não se conhecem

Ligar plataformas que nunca foram feitas para trabalhar juntas: mensageria,
marketplace, CRM, serviço de IA.

Quando não existe API oficial, entra **Playwright**, sabendo que é a solução
mais frágil das disponíveis.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🧰 Ferramentas pequenas

Utilitário que resolve um problema específico e resolve bem, em vez de resolver
dez pela metade.

Costuma nascer de um problema que eu mesmo tive duas vezes seguidas.

</td>
<td width="50%" valign="top">

### 🤖 Experimentos com IA

Testar onde um modelo ajuda de verdade, para escrever texto, classificar ou
extrair, e onde ele só adiciona uma forma nova de errar.

Sempre com validação da resposta e um caminho de saída quando ele falha.

</td>
</tr>

## Coisas que eu aprendi quebrando

- **Se rodar duas vezes quebra, ainda não está pronto.** Vale para todo processo automático.
- **O porquê é o que se perde primeiro.** Daqui a três meses o código continua lá, a decisão não.
- **"Funciona aqui" e "está testado" são coisas diferentes.** Descobri isso do jeito difícil, mais de uma vez.
- **Um número errado na tela custa mais caro que uma tela feia.** Por isso valor e link nunca saem de um modelo de IA nos meus projetos.
